## About
The index.html file living on this repo's GitHub pages is used in PRODUCTION.
This file is displayed as an iframe on the MTECH Styleguide page (/style-guide) where users copy the signature snippet for their email signatures.

## Logo files hosted on mtecstg.wpengine.com
The logo files referenced in index.html live permanently on the staging subdomain.
Since most MTECH employees' email signatures depend on these files at their permanent addresses, they cannot be moved without breaking the email signatures.
